# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Responsible lawyers maintaining a contract obligations register after an amendment.
Compare proposed changes, inspect source quotations and dependent dates, then record
a decision that controls publication of a new version.

## Operating context

The existing Python CLI reads local YAML registers. The skill interprets supplied
documents; Python validates explicit proposals and performs calendar arithmetic.
The amendment report is self-contained HTML with no network, server or account.
Local-report-first is an implementation assumption pending user feedback.

## Constraints

Original registers and sources remain intact. Approval is a supplied attestation,
not authenticated authority. Ambiguity blocks publication. Calendar exports do not
change external calendars. All demonstrations and decisions are labelled synthetic.
